# Water Sort Puzzle

A mobile-friendly Water Sort puzzle game.

Sort the colored water into bottles so each bottle holds only one color. Tap a bottle to select it, then tap another to pour.

**Play now:** [evgeny.io/games/water-sort](https://evgeny.io/games/water-sort/)

The live game is the 3D version in [`lab/`](lab/) (Three.js, difficulty tracks, new mechanics). The React version in `src/` is the previous game and is no longer deployed.
